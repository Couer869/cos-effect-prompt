# COS 人像综合处理词库

服务于 `face_retouch` / `hair_enhancement` / `clothing_refresh` 三个模块。每条给出**可直接放进 JSON 值的中文表述**，以及对应的严禁项（会拼进 `constraints`）。

> 通用铁律：一切修改以"**认得出是本人、自然不过度**"为底线。磨皮不能磨成塑料脸，瘦脸不能改变五官结构，闪粉不能糊到脸上。

## 一、face_retouch（修脸）

用户说"修脸 / 磨皮 / 美肤 / 瘦脸 / 眼睛 / 妆容 / 祛痘"等时启用。

| 子项 | 键 | 可用的 JSON 值 |
|---|---|---|
| 皮肤磨皮 | `skin` | 细腻均匀的皮肤质感，保留真实毛孔细节不失真，肤色通透自然 |
| 祛瑕疵 | `blemish` | 清除痘印、黑眼圈、法令纹、色斑等瑕疵，处理自然无痕，不改变面部光影结构 |
| 瘦脸/下颌线 | `slim_face` | 轻微修饰下颌线与脸颊轮廓，脸型更精致，保持五官自然比例不失真 |
| 眼睛 | `eyes` | 眼睛明亮有神，添加柔和眼神光，轻微放大眼型，保持神态自然 |
| 妆容增强 | `makeup` | 增强妆容层次（眼影/口红/腮红/眼线），颜色与角色气质和服装色系协调 |
| 发际线/碎发 | `hairline` | 整理发际线与碎发，发型干净利落，不改变发型整体轮廓 |

### 严格项
- 严禁过度磨皮导致皮肤失去纹理（塑料感 / 假面感）
- 严禁改变五官结构、比例或位置，导致认不出本人
- 严禁美白/改色导致肤色与画面其他部分脱节

### 强度措辞
- 轻＝只清瑕疵、保留真实肤质；中＝明显美肤但自然；强＝精致无瑕、强调妆感

### 专业修图措辞（已学习用户预设优化词）
- **磨皮/肤质**：中性灰+高低频分离，移除原始毛孔后重绘均匀精致新毛孔（约原始 50-60%），T区略密两颊略疏，保留高低频纹理层次避免塑料感
- **轮廓**：消除双下巴、添加清晰下颌线，定位眉弓与颧骨
- **眼睛**：原本瞳色提亮，绘制添加 catchlights（眼神光）与卧蚕
- **光影**：面部光影均匀自然，影视级棚拍质感
- **唇部**：削弱唇纹、水润质感
- **细节**：移除遮面碎发
- **妆容**：根据 Cos 角色 IP 人设匹配妆容微调，严禁大幅重画

### 修容风格变体
| 风格 | 用户怎么说 | 措辞要点 |
|---|---|---|
| 自然感修容 | "自然感" "自然修容" | 保持妆容不变，消除黑眼圈/眼袋/法令纹/鱼尾纹/唇纹/笑纹/鼻周阴影/痘印/皱纹老化下垂；柔和唇妆腮红修容；肤色均匀年轻水嫩，影视级光影 |
| 厚涂感修容 | "厚涂" "手绘感修容" | 分析角色 IP 添加精致 cosplay 妆：手绘睫毛+shimmering 眼妆+catchlights+卧蚕+T区高光+修容阴影+水润唇；奶油肌水润光泽 |
| CG感修容 | "CG感" "游戏CG" | 实拍 cosplay 转高精度 3D CG 游戏美术级：韩式 VFace、16K 皮肤纹理、精致毛孔、角色补妆 |

## 二、hair_enhancement（头发优化）

用户说"头发 / 发丝 / 亮晶晶 / 闪粉 / 光泽 / 发质"等时启用。核心卖点之一：**亮晶晶头发**。

| 子项 | 键 | 可用的 JSON 值 |
|---|---|---|
| 发丝光泽 | `gloss` | 发丝呈现丝绸般的顺滑光泽，高光随发丝走向自然流动，发质看起来健康亮泽 |
| 亮晶晶闪粉 | `sparkle` | 发丝间点缀细碎亮晶晶的闪粉与星尘光点，如星光洒落，璀璨梦幻 |
| 发丝细节 | `detail` | 发丝根根分明、层次丰富，避免糊成一团，边缘自然融入背景 |

### 变体
- 星尘 / 星光：细小白金光点散落发间
- 彩闪：彩色亮片（蓝/紫/粉）点缀，适合赛博/梦幻风
- 高光染色：发丝边缘带同色系高光挑染（如银白、粉紫）

### 严格项
- 严禁闪粉/光点溢出到面部、服装或背景造成杂乱
- 严禁发丝糊成一团或出现多余发丝
- 严禁改变发型轮廓（长度、卷直、刘海形状）

### 强度措辞
- 轻＝自然光泽，仅极少量光点；中＝明显亮晶晶，光点均匀分布；强＝璀璨星尘、满发星光

### 专业头发措辞（已学习用户预设优化词）
- **超写实质感**：升级为 ultra-realistic 超写实头发纹理，每根发丝可辨的精细 CG 质感（参考 XGen 毛发渲染）；发丝呈自然的粗细渐变（根部粗、尖端极细）
- **材质质感**：丝滑水润（silky and hydrated），健康毛鳞片排列；消除假发合成纤维的塑料光泽与过亮反光，替换为哑光丝滑（Roughness 0.35-0.55）
- **高光**：柔和自然光泽 + 各向异性高光（Anisotropic）沿发丝方向分布；CG 级可用双重高光（Marschner 光学模型：主高光 + 二次色偏高光）
- **微闪钻光点**（亮闪闪细化）：随机选 20-30 根极细发丝，添加微观多色闪烁光点（白/浅金/浅蓝/浅粉，Opacity 20-40%），每根 3-8 个光点，如同发丝上镶嵌极小微钻
- **发束结构**：头发以 3-8 根为一组形成自然发束，每束末端收紧汇聚；发尾自然收尖渐细，禁止齐切或毛糙断裂
- **刘海修整**：统一刘海发丝走向，填补稀疏区域（新发丝颜色粗细光泽与原有完全匹配），假发网/发际线露出时用刘海发丝自然遮盖，保持剪裁轮廓（齐/斜/空气刘海）不变
- **清理**：移除飞散杂发、毛躁、遮挡面部/肩部/手臂的散落发丝，解开缠绕打结，修复分叉干枯发尾

### 头发风格变体
| 风格 | 用户怎么说 | 措辞要点 |
|---|---|---|
| CG 写实 | "CG毛发" "写实毛发" | XGen 级每根发丝可辨、粗细渐变、自投影与 AO、逆光 SSS 透光、双重高光 |
| 手绘赛璐璐 | "手绘感" "赛璐璐" "日系" | 发色概括 2-3 色块、明暗 2-3 级锐利分界、高光条带状、发束 5-15 根带深色轮廓线；面部保持写实 |
| 亮闪闪 | "亮闪闪" "闪钻" "星星发" | 哑光 CG 底 + 微观多色闪钻光点 |

### 长发飘动（吹风物理）
用户要"长发飘动 / 风吹发丝"时，`wind_effect.hair` 按物理逻辑写：
- 发根到中段约前 30% 固定不动；中段开始微弱跟随风向偏移（5-15 度）；发梢轻盈飘散（15-45 度），最大自由度
- 下垂长发在风中呈自然弧线抛物线；飘起发丝之间留自然间隙透出背景
- 统一风向与衣物飘动方向一致；可加 5-10 根略亮单独发丝增加空气感；飘动区域材质光泽与原图一致
- 发丝移动后原位置需重建背景

### 画笔引导（可选）
用户用红色画笔在照片上画了发丝流向/箭头 → 发丝飘动与流向**以红笔方向为准**，在该模块注入 `brush_guidance`（明确红笔标记是方向指示、不残留成片）。

## 三、clothing_refresh（服装优化与瑕疵修复）

用户说"衣服 / 褶皱 / 面料 / 瑕疵 / 污渍 / 破损 / 起球 / 开线"等时启用。在原有的面料/褶皱/贴合基础上扩展瑕疵修复。

| 子项 | 键 | 可用的 JSON 值 |
|---|---|---|
| 面料焕新 | `fabric` | 服装面料呈现崭新柔滑质感，消除起球、磨损与暗沉 |
| 褶皱管理 | `wrinkle` | 移除不美观的堆积褶皱，保留张力褶与自然垂坠感 |
| 合身贴合 | `fit` | 服装更贴合身体曲线，不改变版型与服饰结构 |
| 瑕疵修复 | `flaw_fix` | 修复服装瑕疵：污渍、油渍、破损、撕裂、脱线、五金件缺失/断裂、印花褪色，修复后自然无痕 |

### 严格项
- 严禁破坏服装原有版型、裁剪与花纹图案
- 严禁瑕疵修复后留下色块或涂抹痕迹
- 严禁改动服装可辨识的标识/徽章/图案（除非用户明确要求）

### 强度措辞
- 轻＝只修明显瑕疵；中＝面料焕新+修瑕；强＝整衣翻新、质感提升
