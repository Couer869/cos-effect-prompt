# MJ 生图风格知识库

把 Midjourney 的视觉风格语汇**转译成 Nano Banana 指令可用的描述**。当用户提到「MJ 风格」「MJ 感」「Midjourney 那种效果」，或指定某种审美风格（二次元/厚涂/赛博/电影感/梦幻/写实…）时，从这里取措辞注入指令。

## 一、MJ 核心风格 → 指令措辞

| MJ 风格 | 用户怎么说 | 可用的指令措辞 |
|---|---|---|
| 二次元动漫 | "二次元""动漫感""日系" | 日系动漫风格，干净利落的线条，明快通透的色彩，柔和平涂的阴影，背景细腻 |
| 3D 渲染 | "3D感""CG""游戏建模" | 高精度3D渲染，PBR材质，次表面散射，全局光照与体积光（特效默认风格） |
| 电影感 | "电影感""大片""影视级" | 电影级构图与调色，浅景深，体积光，胶片颗粒，氛围叙事感 |
| 赛博朋克 | "赛博""霓虹""夜之城" | 霓虹光污染，冷调高对比，雨湿街道倒影，全息投影，都市夜景 |
| 梦幻空灵 | "梦幻""仙气""精灵""奇幻" | 柔和光晕，雾霭弥漫，细碎光尘粒子，轻盈通透的半透明质感 |
| 厚涂手绘 | "厚涂""手绘感""油画感" | 厚涂/油画笔触，浓郁有层次的色彩，光影堆叠，颜料质感 |
| 写实照片 | "写实""真实感""摄影感" | 超写实摄影质感，真实光影与皮肤纹理，高细节（8K 级） |
| 极简高级 | "极简""高级感""留白" | 简洁构图，大面积留白，低饱和高级灰，克制配色 |

## 二、MJ 参数 → 指令等价表达

MJ 用参数控制画面（`--ar`、`--v`、`--stylize` 等），Nano Banana 没有这些参数，**翻译成描述性措辞**：

| MJ 参数 | 含义 | 指令等价表达 |
|---|---|---|
| `--ar 16:9` / `9:16` | 画幅比例 | "画面比例保持原图"；或明确 "16:9 横版" / "9:16 竖版" |
| `--v 6` / `--v 7` | 版本审美差异 | "细节与质感对齐 Midjourney 6/7 代审美"（6 代偏写实平衡、7 代更丰富） |
| `--stylize` / `--s` | 风格化强度 | 低 → "克制写实，减少艺术化加工"；高 → "大胆艺术化，表现力强" |
| `--style raw` | 少风格化 | "保留真实摄影质感，不套滤镜" |
| `--no 物体` | 排除内容 | 转写进 `constraints` 的「禁止」项 |
| `--chaos` | 随机多样性 | 不需要（指令要确定性，不引入随机） |

## 三、MJ 风格注入方法

用户要求 MJ 风格时：

1. **选措辞**：从上面「MJ 核心风格」表取对应的指令措辞
2. **注入位置**：
   - 特效 → 写入 `special_effects.style`（覆盖默认 CG 质感，或与之并列）
   - 整体画面 → 在 `content` 里加一句风格定调，或写进相关模块的 `blend`
   - 修图 → 写进 `face_retouch` / `hair_enhancement` 的质感描述
3. **MJ 参数 → 措辞**：用户提到 `--ar` / `--v` / `--stylize` 时，按上表转译成描述性语句

## 示例

用户："想要 MJ 那种二次元厚涂的感觉，氛围梦幻一点"

指令注入：
```json
"special_effects": {
  "style": "日系动漫 + 厚涂手绘质感：干净线条、通透色彩、浓郁层次的光影堆叠，搭配柔和光晕与细碎光尘，梦幻空灵氛围，细节丰富度对齐 Midjourney 审美",
  "effects": [ ... ]
}
```

## 五、风格识别维度

识别一张图 / 一段描述属于什么风格，从 5 个维度对照上面的风格表：

| 维度 | 各风格表现 |
|---|---|
| **线条** | 干净硬边（二次元 / 3D）｜柔和模糊（梦幻 / 电影）｜明显笔触（厚涂） |
| **色彩** | 通透明快（二次元）｜浓郁层次（厚涂）｜冷调霓虹（赛博）｜低饱和（极简 / 写实） |
| **光影** | 平涂阴影（二次元）｜体积光 / 全局光（3D / 电影）｜强对比光污染（赛博）｜柔和光晕（梦幻） |
| **质感** | 手绘颜料感（厚涂）｜高精渲染感（3D / CG）｜真实摄影感（写实） |
| **氛围** | 空灵（梦幻）｜未来（赛博）｜叙事（电影）｜高级简约（极简） |

多风格叠加时按主次列出（如"二次元厚涂，梦幻氛围"）。内置库识别不出的 → 走风格学习，收录进 `styles-learned.md`。
