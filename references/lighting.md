# 光影重塑模块

服务 `lighting_reshape` 模块：**系统化重塑照片的光照**。用户提到"重塑光影 / 打光 / 布光 / 改光 / 逆光 / 侧光 / 色温 / 电影光"时启用。光影重塑是"加法改光"，不是"全局调色"——新光源要为角色补光、营造氛围，但要保持画面物理一致。

## 触发词

重塑光影 / 打光 / 布光 / 改光方向 / 逆光 / 侧光 / 顶光 / 底光 / 补光 / 轮廓光 / 色温 / 冷暖光 / 电影光 / 三点布光

## 一、模块结构

```json
"lighting_reshape": {
  "action": "重塑光线",
  "target": "整体光源",
  "lighting_scheme": "三点布光 / 单主光 / 逆光 / 侧光 / 顶光 / 底光 / 环境光",
  "key_light": "主光方向、强度、色温",
  "fill_light": "辅光强度与位置（柔和补亮暗部）",
  "rim_light": "轮廓光（勾勒边缘，与背景分离）",
  "ambient": "环境光与氛围色",
  "color_temp": "色温倾向（暖金/冷蓝/中性）",
  "light_ratio": "光比（明暗对比强弱）",
  "goal_description": "期望的光影画面（看得见：哪些亮、哪些暗、边缘光等）",
  "preserve": "人物五官、动作、构图",
  "blend": "所有阴影高光随新光源方向统一重算，保持光影物理一致"
}
```

## 二、布光方案

### 三点布光（标准人像）
- **主光**：角色前方 30-45° 侧上方，决定主体明暗
- **辅光**：主光对侧，柔和补亮暗部（光比决定立体感）
- **轮廓光**：背后逆光，勾勒发丝与肩线，与背景分离
- 措辞：`主光从左上 45° 打向面部，右侧辅光柔和补暗部，背后轮廓光勾勒发丝边缘`

### 逆光 / 轮廓光
- 主体背后强光，边缘亮、面部微暗，发丝透光，背景压暗
- 措辞：`逆光勾勒人物轮廓，发丝透光，边缘有柔和光晕，背景自然压暗突出主体`

### 侧光 / 戏剧光
- 主光从正侧打来，脸一半亮一半暗（伦勃朗光），高对比有戏剧感
- 措辞：`侧光从正侧照亮半张脸，形成伦勃朗光，明暗对比强烈，面部有立体层次`

### 顶光 / 底光
- 顶光：如正午/顶灯，五官下阴影明显
- 底光：自下而上，诡异/反派/舞台感
- 措辞：`顶光从正上方打下，鼻下与下颌有清晰阴影` / `底光从下方打亮下颌，营造神秘氛围`

### 环境光 / 氛围色
- 暖金（黄昏/烛光）、冷蓝（月夜/科技）、混合色（霓虹冷暖对冲）
- 措辞：`环境光为暖金色，氛围温馨` / `环境光冷蓝，月光洒落`

## 三、色温重塑

| 色温 | 画面倾向 | 措辞 |
|---|---|---|
| 暖金 | 黄昏/烛光/复古 | 暖金色调，暗部带琥珀色，高光柔和 |
| 冷蓝 | 月夜/科技/清冷 | 冷蓝色调，暗部偏青，高光清透 |
| 中性 | 棚拍/真实 | 中性色温，还原真实肤色 |
| 混合 | 霓虹/冲突 | 冷暖对冲，半边暖半边冷，氛围强烈 |

## 四、光比（明暗对比）

| 光比 | 效果 | 措辞 |
|---|---|---|
| 低光比 | 柔和、明亮、少女感 | 光比柔和，暗部补光充足，整体明亮通透 |
| 中光比 | 自然、日常 | 光比适中，明暗过渡自然 |
| 高光比 | 强烈、戏剧、酷感 | 光比强烈，阴影深沉，高光锐利，明暗对比鲜明 |

## 五、使用注意

- 光影重塑是**系统性改光**：新光源方向一旦定下，全图的阴影、高光、反射都随之统一（呼应透视/光影一致性硬规则）
- 严禁：只改部分区域导致光源混乱（多头灯）；过度压暗/过曝丢失细节；为"氛围"牺牲人物辨识度
- 与 `blend_strength` 参数联动：光影融入越强，布光越明显
