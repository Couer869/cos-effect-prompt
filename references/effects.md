# COS 后期特效词库

按四大类组织。每个特效给出：
- **视觉描述**：可直接放进提示词的中文画面描述（核心）
- **融入写法**：如何让特效"长在"照片里（光影 / 透视 / 图层逻辑）
- **强度词**：克制 ↔ 明显 ↔ 强烈 的措辞切换
- **变体**：常见分支

> 用法：本词库只服务于 SKILL.md 组装流程中的 `special_effects` 模块。把每个特效的措辞映射进 JSON 字段：
> - 「视觉描述」→ `visual_description`
> - 「融入写法」→ `blend`
> - 「强度词」→ `intensity`（轻/中/强）
> - `type` / `location` 取特效名与位置惯例
>
> 特效写进照片时一律保持"保持人物不变"的前提，不要把特效画到角色脸上/身上导致重绘人物——相关约束由 SKILL.md 第 4 步拼进 `constraints`。

## 特效质感：CG / 建模画风（默认）

特效**默认以 CG 质感 + 建模画风呈现**——像高端游戏过场动画里的 3D 特效，而不是实拍贴图或平面画上去的。用户提到「CG / 建模 / 游戏CG / 二次元渲染 / 卡通渲染 / 质感」时，就是要求这种风格；用户没提时**也默认按这个风格写**。

**通用质感措辞**（附加在每条特效 `visual_description` 末尾）：
> 以高精度3D渲染质感呈现，表面平滑细腻、边缘清晰锐利，光效具有体积感与全局光照感，类似高端游戏过场CG的特效表现

**通用融入调整**（加到 `blend` 里）：
> 特效以CG材质渲染，光影遵循物理规律（体积光/环境反射/次表面散射），与照片中角色形成高质量的融合，避免扁平贴图感

**强度对应的 CG 化措辞**（强度词在 CG 风格下的表达）：

| 强度 | CG 化表达 |
|---|---|
| 轻 | 细腻克制的CG光效，质感低调高级 |
| 中 | 清晰的3D特效，材质与体积光表现完整 |
| 强 | 华丽浓烈的CG爆发特效，满屏体积光与粒子，视觉冲击强 |

**其他风格（用户明确要求时覆盖默认）：**

- **写实实拍 VFX**：真实电影特效质感，粒子与烟雾物理真实，避免3D建模感
- **二次元手绘**：赛璐璐/厚涂手绘质感，线条感强，柔和平涂
- **扁平贴图**：简约平面光效，无体积感，适合极简清新风

## 一、元素类特效

### 火焰
- **视觉描述**：燃烧跃动的火焰从{位置}升腾而起，火舌卷动，火星与热浪四溅，橙红与金黄交织
- **融入写法**：火焰的光应照亮角色的受光面，产生暖橙色的环境光晕，投影方向与照片原有光源一致
- **强度**：轻＝淡淡摇曳的火焰光晕 / 中＝清晰的火焰升腾 / 强＝熊熊烈焰包裹、大面积火光
- **变体**：火焰拖尾（角色身后拖出火痕）、冷焰（青蓝色）、圣火（纯白金焰）、蓝火幽灵焰

### 冰霜
- **视觉描述**：晶莹的冰晶与霜花从{位置}蔓延生长，冰蓝色半透明质感，表面折射冷光，细碎的冰屑悬浮在空气中
- **融入写法**：冰霜反射偏冷的环境光，给角色加一层淡青色的冷调补光，注意冰的透明与反光层次
- **强度**：轻＝薄霜微凝 / 中＝冰晶明显凝结 / 强＝大块冰封、冰雾弥漫
- **变体**：冰冻裂纹（地面/武器裂纹蔓延）、冰锥、暴风雪冰晶、冰莲

### 雷电
- **视觉描述**：蜿蜒的电弧从{位置}迸发，蓝紫色电流分枝闪烁，周围空气因电离泛起微光，细小电流粒子跳跃
- **融入写法**：电弧光晕应瞬间照亮角色轮廓，产生蓝紫高光与轻微光污染，电流节点处光最亮
- **强度**：轻＝指尖细碎电流 / 中＝清晰电弧分支 / 强＝粗壮雷柱轰击、辐射状电芒
- **变体**：球形闪电、雷纹（皮肤/衣物上蔓延的发光纹路）、电光护盾

### 水 / 海浪
- **视觉描述**：清澈的水流围绕{位置}流动，水花飞溅，半透明的浪花与飞沫在光下泛着晶莹的亮点
- **融入写法**：水体折射与反射环境光，人物与水接触处应有湿润反光，保持水的透明层次
- **强度**：轻＝水滴漂浮 / 中＝水流环绕 / 强＝漩涡巨浪
- **变体**：水幕、冰水混合、墨色水、荧光水母般的水流

### 风 / 气流
- **视觉描述**：流动的气流环绕{位置}旋转，形成可见的旋涡与风刃轨迹，衣角发丝随气流扬起
- **融入写法**：风的效果要通过带动衣物、发丝、发丝边上的轻尘来体现，气流轨迹呈半透明丝带状
- **强度**：轻＝微风浮动 / 中＝明显气流旋涡 / 强＝龙卷风暴
- **变体**：风刃（弧形白色切割线）、青色气旋、羽毛与花瓣卷入风中

### 光 / 圣光
- **视觉描述**：温暖圣洁的光从{位置}倾泻而下，形成光束与光斑，光中浮动着细小的尘埃粒子
- **融入写法**：光束要有体积感（丁达尔效应），光照射到角色身上产生柔和高光与阴影过渡
- **强度**：轻＝柔光笼罩 / 中＝清晰光柱 / 强＝强光喷涌、过曝高光
- **变体**：金色神性光、天光、聚光灯、彩色棱镜光

### 暗影 / 黑暗
- **视觉描述**：浓稠的暗影能量从{位置}翻涌扩散，黑紫色雾气缠绕，边缘泛着微光
- **融入写法**：暗影吞噬局部光照，角色被影笼罩的一侧压暗，与光亮侧形成明暗对比
- **强度**：轻＝暗色雾气 / 中＝翻涌的影能量 / 强＝几乎吞噬背景的黑暗领域
- **变体**：紫黑魔气、影子触手、黑暗领域、暗蚀地面

### 土 / 岩石
- **视觉描述**：碎裂的岩石与尘土从{位置}升起悬浮，碎石表面刻有发光纹路，尘土颗粒在光中可见
- **融入写法**：石块受光与照片光源一致，悬浮石块保持正确透视关系
- **强度**：轻＝零星碎石 / 中＝岩石悬浮环绕 / 强＝巨大岩柱拔地而起
- **变体**：土黄色岩流、晶簇矿脉、玄武岩柱

## 二、魔法 / 奇幻类

### 魔法阵
- **视觉描述**：{位置}浮现一座发光的魔法阵，繁复的几何图纹与神秘符文环绕旋转，符文线条柔和发光
- **融入写法**：魔法阵光应与角色形成交互——光芒映照在角色身上产生同色相的环境光，地面阵法要有正确透视（俯视投影）
- **强度**：轻＝淡淡的光纹轮廓 / 中＝清晰可辨的法阵 / 强＝多层嵌套、强光脉冲的巨大法阵
- **变体**：金色审判阵、紫色传送阵、冰蓝色召唤阵、脚下圆形/背后圆形/悬浮竖阵

### 符文 / 咒文
- **视觉描述**：悬浮的发光符文环绕{位置}飘动，古老的文字与符号缓慢旋转，散发幽微的光
- **融入写法**：符文亮度与照片光环境协调，光晕落在角色身上自然过渡
- **强度**：轻＝零星字符漂浮 / 中＝符文环带环绕 / 强＝大量符文如星云般涌出
- **变体**：金色古篆、蓝色科技符文、血色咒印

### 光环 / 天使环
- **视觉描述**：{头顶/脑后}悬浮一轮柔和发光的圆环，光晕清透，边缘略微过曝
- **融入写法**：光环应有轻微景深虚化感，与背景融合而非生硬贴在头上，光环透出的光映亮面部上方
- **强度**：轻＝细光环带 / 中＝清晰光环 / 强＝多重光环+强烈圣光
- **变体**：金色圣环、黑色恶魔环、碎裂纹光环、旋转星座环

### 翅膀
- **视觉描述**：{背后}展开一双{材质}翅膀，羽翼层次分明，边缘透光/金属反光/能量流动
- **融入写法**：翅膀展开要符合透视与比例，根部自然"长"在肩胛位置，注意翅膀在背景中的投影
- **强度**：轻＝半透明光翼虚影 / 中＝清晰翅膀展开 / 强＝巨大翅膀遮天蔽日
- **变体**：白色羽翼、黑色恶魔翼、机械金属翼、火焰/能量光翼、蝴蝶翼、骨翼

### 粒子 / 光尘
- **视觉描述**：细小的发光粒子如萤火般漂浮在空气中，大小不一，聚散离合，营造梦幻氛围
- **融入写法**：粒子应有景深——前景粒子虚化、背景粒子柔和，与照片光线方向呼应
- **强度**：轻＝零星几点微光 / 中＝均匀漂浮的光尘 / 强＝漫天星光粒子
- **变体**：萤火虫、星尘、金粉、花瓣形光点、数据粒子

### 能量波 / 冲击
- **视觉描述**：从{位置}爆发环形冲击波，半透明能量波纹向外扩散，空气扭曲泛起涟漪
- **融入写法**：冲击波半透明且带有扭曲背景的折射感，波前最亮，能量衰减逐渐透明
- **强度**：轻＝细微波纹 / 中＝清晰冲击环 / 强＝爆炸级能量喷发
- **变体**：气功波、能量球、引力波、音波环

### 圣光降临
- **视觉描述**：天幕裂开一道光隙，神性光束倾泻而下，光中飘落羽毛与光斑，周围一切被照亮
- **融入写法**：光束要有穿透云层/天花板的体积感，照亮区域产生圣洁高光
- **强度**：轻＝薄云透光 / 中＝清晰光束 / 强＝满屏圣光过曝
- **变体**：教堂彩窗光、云端圣光、粒子圣光

## 三、氛围光效类

### 轮廓辉光 / 背光
- **视觉描述**：角色{整体/局部}边缘泛起柔和的光晕，勾勒出清晰的轮廓线，光从背后透出
- **融入写法**：轮廓光是逆光拍摄的自然延伸，头发与衣物边缘最亮，向内部柔和衰减
- **强度**：轻＝淡淡描边光 / 中＝明显轮廓光 / 强＝高对比逆光剪影
- **变体**：暖金逆光、冷蓝逆光、霓虹描边

### 镜头光晕 / 眩光
- **视觉描述**：光源方向出现彩虹色的镜头光晕，多边形或圆环状眩光，微微过曝
- **融入写法**：光晕应出现在强光源位置（如阳光、路灯），遵循光学规律，不要乱放
- **强度**：轻＝微小的光斑眩光 / 中＝清晰多边形光晕 / 强＝大面积眩光过曝
- **变体**：六边形光晕、环形眩光、上帝光

### 体积光 / 丁达尔光束
- **视觉描述**：空气中出现可看见的光束，穿过{缝隙/树林/云层}洒落，光束内有尘埃与雾气可见
- **融入写法**：光束要有"穿过空气"的体积感，光柱边界柔和，受光处与背光处对比明显
- **强度**：轻＝薄雾中微光 / 中＝清晰光束 / 强＝强烈光柱交错
- **变体**：森林光、教堂光、粉尘光束、水下光束

### 散景 / 光斑
- **视觉描述**：背景虚化成柔和的圆形光斑，层层叠叠，营造梦幻柔焦氛围
- **融入写法**：光斑应出现在背景虚化区，形状均匀、边缘柔和，与前景主体形成景深对比
- **强度**：轻＝轻微虚化光点 / 中＝清晰圆形散景 / 强＝满背景梦幻光斑
- **变体**：彩色泡泡、星形散景、爱心散景

### 霓虹 / 赛博光
- **视觉描述**：画面融入冷色调霓虹灯光，紫蓝洋红的发光线条与光晕，地面有灯光倒影与反光
- **融入写法**：霓虹光应给角色补一层同色相的环境光，皮肤与衣物边缘带霓虹反光，湿地面有光晕倒影
- **强度**：轻＝点缀式霓虹灯条 / 中＝明显霓虹氛围 / 强＝全画面赛博光污染
- **变体**：粉色霓虹、青紫赛博、蓝红警戒光、全息投影光

### 电影调色 / 色调
- **视觉描述**：整体调整为{风格}电影色调，色调统一，暗部沉稳、高光带色，氛围感强烈
- **融入写法**：调色要统合全图，人物肤色与背景同色系协调，避免局部变色
- **风格**：冷青蓝调（清冷/科技）、橙青互补（商业大片）、低饱和灰调（压抑/纪实）、暖金复古（怀旧）、黑金（暗黑高级）
- **变体**：LUT 电影感、胶片颗粒、暗角、青橙对比

### 光尘 / 丁达尔尘
- **视觉描述**：空气中有细小的尘埃微粒在光束中闪闪发光，增加画面质感和空气感
- **融入写法**：尘埃聚集在光束路径上，前实后虚，增强空间纵深
- **强度**：轻＝隐约可见 / 中＝明显浮尘 / 强＝光尘浓密
- **变体**：雪絮般浮尘、金色浮尘、水下浮尘

## 四、场景类特效

### 雨天 / 暴雨
- **视觉描述**：画面中加入连绵的雨丝，雨滴下落轨迹清晰，地面泛起水花与涟漪，湿润反光
- **融入写法**：雨丝方向一致、带轻微模糊感，角色肩头与头发有湿润感，地面反光增强
- **强度**：轻＝细雨蒙蒙 / 中＝明显雨丝 / 强＝倾盆大雨、水雾弥漫
- **变体**：雨夜霓虹倒影、雨天撑伞、暴雨战损

### 下雪 / 飞雪
- **视觉描述**：漫天雪花飘落，雪花大小不一，近处大而清晰、远处小且虚化
- **融入写法**：雪景降低环境对比度、色调偏冷，角色肩头落雪增加真实感
- **强度**：轻＝零星雪片 / 中＝纷纷扬扬的雪 / 强＝暴风雪、视野遮蔽
- **变体**：雪夜、初雪、雪中散落的羽毛混雪

### 花瓣 / 花雨
- **视觉描述**：无数{樱花/花瓣}随风飘落，粉色花瓣在半空中旋转，铺满地面一层
- **融入写法**：花瓣带景深虚化，前景花瓣大而模糊，整体色调柔美粉嫩
- **强度**：轻＝少量飘落 / 中＝花瓣纷飞 / 强＝花瓣漫天、满地落英
- **变体**：樱花雨、玫瑰花瓣、枫叶飘落、萤火虫+花瓣

### 爆炸 / 冲击
- **视觉描述**：{位置}发生剧烈爆炸，橙红火光与浓烟翻滚，碎片四溅，强光瞬间照亮周围
- **融入写法**：爆炸的光源应与角色形成强烈明暗对比，火光映红角色受光面，背景过曝
- **强度**：轻＝小型爆燃火花 / 中＝明显爆炸火球 / 强＝大爆炸蘑菇云
- **变体**：玻璃破碎炸裂、能量爆炸（无火）、爆炸冲击波及飞沙走石

### 废墟 / 末世
- **视觉描述**：背景转化为{城市废墟/荒芜战场}，断壁残垣、锈蚀金属、扬起的尘土，末日氛围
- **融入写法**：废墟应与原图视角一致，远处朦胧、近处清晰，色调偏灰暗加一层青灰色霾
- **强度**：轻＝局部破损 / 中＝明显废墟化 / 强＝整片末世战场
- **变体**：赛博废墟、哥特古堡、魔法遗迹、太空废墟

### 赛博朋克街景
- **视觉描述**：背景替换为霓虹闪烁的赛博朋克都市夜景，摩天楼群、全息广告、雨湿街道倒影
- **融入写法**：角色受霓虹补光（紫蓝粉交替），地面湿反光，整体冷调高对比
- **强度**：轻＝霓虹背景点缀 / 中＝明显赛博街景 / 强＝全沉浸赛博世界
- **变体**：九龙城寨风、银翼杀手雨夜、全息数据街、地下黑市

### 星空 / 银河
- **视觉描述**：背景化为深邃星空，银河横亘，繁星点点，星云色彩斑斓，月光清冷
- **融入写法**：星光微光点缀角色，前景角色保持清晰，星空背景远处虚化
- **强度**：轻＝几点星子 / 中＝清晰星空 / 强＝壮丽银河铺满天空
- **变体**：极光、流星雨、星空剪影、神话星座图

### 哥特 / 古堡
- **视觉描述**：背景转化为哥特式古堡内部或外景，石柱拱窗、烛火昏暗、彩绘玻璃透光
- **融入写法**：烛光暖调与冷调月光对比，角色被烛火映亮一侧暖、另一侧冷
- **强度**：轻＝古堡氛围点缀 / 中＝明显古堡场景 / 强＝整景哥特殿堂
- **变体**：吸血鬼古堡、教堂彩窗、中世纪城堡、禁地祭坛

## 通用强度措辞对照

| 强度 | 特效本身 | 光影与融合 |
|---|---|---|
| 轻（克制） | 淡淡的 / 若有若无 / 轻微地 | 低调融入，几乎不改变原光影 |
| 中（标准） | 清晰的 / 明显的 / 自然呈现 | 与角色有自然光交互 |
| 强（张扬） | 强烈的 / 汹涌的 / 炽烈的 | 强烈照亮/包裹角色，光影变化明显 |
