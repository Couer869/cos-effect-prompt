# 服装材质库

服务 `clothing_refresh` / `clothing_fix` 模块的**材质细化**与 **C 服还原度检查**。用户提到具体材质（缎面/雪纺/皮革/蕾丝/金属…）或 C 服还原需求时使用。

## 一、布料材质措辞

| 材质 | 用户怎么说 | 指令措辞要点 |
|---|---|---|
| **缎面 / 丝绸** | "缎面""丝绸""绸缎" | 平滑如镜的高反光表面，高光呈柔和的带状流动，褶皱少而大，垂坠感强，光泽随身体曲线变化 |
| **雪纺 / 纱** | "雪纺""薄纱" | 半透明轻薄，透出内层肤色与底裙，边缘有细碎飘动，光线下呈柔光晕散 |
| **蕾丝** | "蕾丝""花边" | 精密镂空花纹，透光见肤，边缘有细腻花边，光线下花纹投影分明 |
| **皮革** | "皮革""皮衣" | 硬挺有型的反光材质，高光锐利集中，表面有自然褶皱与纹理，质感厚重 |
| **金属** | "金属""铠甲""亮片" | 高对比镜面反射，环境光映在表面，边缘有锋利高光，可能带氧化暗部 |
| **绒面 / 丝绒** | "丝绒""天鹅绒""麂皮" | 哑光吸收光线，颜色浓郁深沉，有柔和的光晕变化，触感厚重 |
| **棉麻** | "棉质""麻料" | 哑光自然，褶皱细密而多，透气干爽质感，光线下柔和 |
| **PVC / 人造革** | "PVC""漆皮" | 塑料光泽，高光极亮而硬，表面反光强烈，可能带气泡瑕疵需修复 |
| **皮草 / 绒毛** | "皮草""绒毛""毛领" | 细密绒毛层次，光线下有蓬松光晕，毛流方向一致 |

## 二、材质光效与褶皱特性

- **反光型**（缎面/皮革/金属/PVC）：高光锐利、随身体曲面变化，褶皱少但大；补光易过曝，需控制光比
- **透光型**（雪纺/纱/蕾丝）：半透明、边缘透光，内层可见；光下呈柔光晕散，避免生硬描边
- **吸光型**（绒面/丝绒/棉麻）：哑光低反光，颜色浓郁，褶皱细密；补光要柔，避免死黑

## 三、C 服还原度检查

用户提到"C服还原""还原度""复刻角色服"时，在 `clothing_refresh` 或对应模块附上检查清单：

- **版型**：与原作一致——领口、袖型、裙长、轮廓线不擅自改动
- **配色**：按原作色号还原，不得偏色（缎面类尤其注意高光偏色）
- **花纹/印花**：图案位置、比例、朝向与原作一致，花纹不断裂不错位
- **五金件**：拉链、纽扣、肩章、徽章、金属装饰齐整且反光自然
- **标志/纹章**：角色专属标志（校徽/家族纹章/阵营标）严格还原，禁止模糊或改动
- **材质区分**：原作不同部位的材质（如上身皮衣+下身纱裙）分开处理，不混为一谈

## 四、材质在模块中的注入位置

- 织物焕新 → `clothing_refresh.fabric`（按材质措辞细化）
- 瑕疵修复 → `clothing_refresh.flaw_fix`（起球/磨损/污渍按材质处理）
- C 服还原 → 独立在 `clothing_refresh` 加 `costume_accuracy` 字段：
```json
"costume_accuracy": "按原作还原服装：版型/配色/花纹/五金件/标志逐项核对，材质按部位区分处理"
```
