# 电影风格仿制

用户提到「仿 XX 电影风格 / 电影感 / 导演风格 / 想要 XX 电影的感觉 / 仿制某部片」时使用。识别风格 → 注入 `style` / 调色 / 光影 / 质感，让画面呈现对应的电影美学。

## 二、注入方法

- **整体色调** → `color_grading`（调色模块）：按风格表的色调措辞
- **光影** → `lighting_reshape`（光影模块）：按风格的光影特征（高对比/硬光/体积光）
- **特效/场景** → `special_effects.style` 叠加电影质感词
- **质感** → 在 `content` 加：`film_grain`（胶片颗粒）、`vignette`（暗角）、`soft focus`（柔焦）等
- 组合示例：仿王家卫 = 霓虹撞色调色 + 暗部沉稳 + 轻微胶片颗粒

## 三、识别维度（反推/识别电影风格）

从 5 个维度判断属于哪种电影风格：

| 维度 | 表现 |
|---|---|
| 色调 | 冷暖 / 撞色 / 褪色 / 黑白 |
| 光影 | 高对比 / 硬光 / 柔和 / 体积光 |
| 质感 | 胶片颗粒 / 柔焦 / 水彩手绘 |
| 构图 | 对称 / 手持 / 辽阔 / 特写 |
| 时代感 | 复古 / 未来 / 现代 |

多风格叠加时按主次列出（如"王家卫式霓虹 + 复古胶片颗粒"）。

## 四、注入示例

用户："想要王家卫电影那种感觉，加个霓虹雨夜"

```json
"color_grading": {
  "action": "调整整体色调",
  "target": "画面整体",
  "goal_description": "仿王家卫电影风格：霓虹撞色(红/绿/蓝高饱和)、暗部沉稳、轻微胶片颗粒、画面有情绪张力",
  "preserve": "人物面部细节、光影结构、动作与构图",
  "intensity": "中",
  "blend": "色调统合全图，人物肤色与背景协调，避免局部变色"
}
```
